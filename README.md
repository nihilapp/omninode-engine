# 옴니노드

하나의 세계관에는 수많은 인물과 장소, 사건과 개념이 함께 살아갑니다. 설정이 깊어질수록 자료는 여러 문서에 흩어지고, 서로 어떤 영향을 주고받는지 한눈에 파악하기 어려워집니다.

옴니노드는 이렇게 쌓여 가는 세계관을 체계적으로 기록하고 연결하기 위한 지식 아카이브입니다. 창작자는 하나의 월드 안에서 여러 프로젝트를 운영하며 설정을 일관되게 관리할 수 있고, 독자는 문서와 문서 사이의 관계를 따라가며 세계관을 자연스럽게 탐색할 수 있습니다.

단순히 문서를 보관하는 데 그치지 않고, 설정이 어떻게 이어지고 변화해 왔는지까지 함께 남기는 것. 그것이 옴니노드가 만들고자 하는 세계관 아카이브입니다.

## 주요 기능

- 월드와 프로젝트 단위의 설정 자료 관리
- 카테고리와 템플릿을 이용한 일관된 문서 작성
- 문서 수정 이력 보존과 공개본 관리
- 태그, 역링크, 문서 간 관계를 통한 설정 연결
- 관계 유형과 관계 그래프를 이용한 세계관 구조 탐색
- 역할과 권한 범위에 따른 공동 관리
- 초대, 계정, 비밀번호와 탈퇴 절차 관리
- 공개 월드·프로젝트·문서 탐색
- 관리자용 월드·프로젝트 현황과 점검 작업 제공
