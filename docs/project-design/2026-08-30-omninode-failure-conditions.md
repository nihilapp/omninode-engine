# 옴니노드 실패 조건

> 분류: 프로젝트 설계
>
> 근거: 확정 1차 기획, 도메인 책임 정의, 권한 매트릭스, 검증 규칙
>
> 범위: 행동을 수행할 수 없는 조건과 그때의 시스템 결과를 정의한다. 화면 문구, HTTP 상태 코드, API 오류 형식은 포함하지 않는다.

## 공통 실패 원칙

1. 검증에 실패한 행동은 대상 도메인의 현재 상태·리비전·연결·공개 상태를 바꾸지 않는다.
2. 권한 부족, 범위 밖 접근, 삭제·비공개·비활성 상태는 행동 목적에 맞는 접근 불가 또는 선택 불가 결과로 처리한다.
3. 이미 확정된 복구·새 생성 선택, 비공개 문서, 삭제 문서, 이전 문서 주소의 표기 규칙은 일반 오류보다 우선한다.
4. 실패를 이유로 새 문서·템플릿 리비전, 관계 이력, 감사 이력을 임의로 만들지 않는다. 실제 상태 변경이 완료된 경우에만 해당 이력을 남긴다.

## 실패 조건과 시스템 결과

| 분류 | 실패 조건 | 시스템 결과 |
| --- | --- | --- |
| 인증 | 로그인하지 않았거나 탈퇴·완전 삭제한 계정이 일반 서비스에 접근 | 일반 서비스 기능을 허용하지 않는다. 탈퇴 계정은 7일 동안 이메일 전용 내려받기 링크만 사용할 수 있다. |
| 권한 | 역할·월드·프로젝트 범위 또는 해당 생성·수정·삭제 허가가 없음 | 행동을 수행하지 않고 대상 데이터도 바꾸지 않는다. |
| 초대 | 대기 초대가 취소·만료됐거나 링크가 유효하지 않음 | 초대를 수락하거나 계정을 생성하지 않는다. |
| 비밀번호 재설정 | 링크가 완료·만료·무효 상태이거나 다른 새 요청으로 대체됨 | 비밀번호를 바꾸지 않는다. 계정 소유자는 새 재설정을 요청할 수 있다. |
| 탈퇴 | 부관리자가 있는 소유 월드에 승계 대상이 지정되지 않음 | 탈퇴 확정을 진행하지 않는다. |
| 중복 | 활성 항목과 월드·프로젝트 이름, 슬러그, 카테고리 이름, 템플릿 이름, 문서상 이름, 태그 이름 또는 관계 구성이 중복 | 새 항목·연결·관계를 만들지 않는다. 삭제된 동명 항목이 있으면 복구 또는 새 생성 절차로 전환한다. |
| 입력 형식 | 월드·프로젝트 슬러그에 허용하지 않은 문자, 문서상 이름의 3개 구간 초과, 유효하지 않은 세계관 시점·이름 입력 | 저장·생성·이름 변경을 수행하지 않는다. |
| 참조 범위 | 다른 월드 문서를 위키링크·관계·태그 대상으로 선택하거나, 다른 월드 프로젝트·카테고리·템플릿을 연결 | 연결·저장·생성을 수행하지 않는다. |
| 카테고리 | 카테고리 깊이가 3단계를 넘거나, 문서·하위 카테고리가 남은 카테고리를 삭제 | 구조 변경·삭제를 수행하지 않는다. |
| 템플릿 | 템플릿이 없는 대분류에서 문서를 만들거나, 비활성 템플릿을 새로 연결·적용하거나, 섹션 코드 변경·삭제·`개요` 위 추가를 시도 | 문서 생성·연결·템플릿 변경을 수행하지 않는다. 다른 구조가 필요하면 새 템플릿을 사용해야 한다. |
| 문서 | 비활성 카테고리로 새 문서를 만들거나 이동하거나, 다른 템플릿 카테고리 이동에서 기존 섹션의 유지·삭제 결정을 마치지 않음 | 문서 생성·이동·새 리비전 저장을 수행하지 않는다. |
| 공개 | 필수 섹션 본문이 비어 있거나 카테고리 이동 점검 필요 상태의 문서를 공개하려 함 | 공개 상태와 선택 공개 리비전을 바꾸지 않는다. |
| 태그 | 부관리자가 태그 목록을 삭제·복구하려 하거나, 삭제된 태그를 새 문서 리비전에 연결하려 함 | 태그 목록 또는 문서 태그 연결을 바꾸지 않는다. 기존 문서 편집의 새 태그 자동 추가는 문서 허가가 있을 때만 가능하다. |
| 관계 | 참여 문서가 2개 미만 또는 4개 초과, 역할별 허용 카테고리·반복 규칙 위반, 비활성 관계 유형 사용, 중복 관계 생성 | 관계를 만들거나 바꾸지 않는다. |
| 관계 유형 | 사용 중인 사용자 정의 관계 유형의 구조 변경·삭제, 비활성화로 종료한 관계의 복구 시도 | 구조 변경·삭제·복구를 수행하지 않는다. 필요한 구조·관계는 새로 만들어야 한다. |
| 공개 열람 | 비공개·삭제 문서를 직접 열람하거나 공개 문서 안의 비공개·삭제 연결을 열람 | 직접 열람은 허용하지 않는다. 공개 문서 안에서는 각각 `비공개 문서`, `삭제됨`으로 표시한다. |
| 공개 주소 | 문서상 이름 변경 전의 주소, 존재하지 않는 월드·프로젝트 슬러그 또는 문서상 이름으로 접근 | 이전 문서 주소는 404로 처리한다. 존재하지 않는 주소도 공개 문서를 열람시키지 않는다. |

## 상태 충돌 처리

1. 카테고리 이동으로 점검 대상이 된 문서는 즉시 비공개가 되며, 관리자가 점검을 완료하기 전에는 공개 반영을 거부한다.
2. 템플릿 변경으로 `템플릿 점검 필요`가 된 문서는 읽기·공개본을 자동 변경하지 않는다. 수정 흐름에서 최신 구조를 저장하면 점검 상태를 해제한다.
3. 관계 유형을 비활성화하면 기존 관계는 종료된 삭제 기록으로 남고, 다시 활성화해도 기존 관계를 되살리지 않는다.
4. 태그 삭제는 현재 문서의 태그 노출과 검색만 해제한다. 과거 리비전 기록은 유지하므로, 해당 기록을 근거로 태그를 자동 복구하지 않는다.
5. 문서 리비전 복원은 관계의 현재 참여 상태를 바꾸지 않는다.
