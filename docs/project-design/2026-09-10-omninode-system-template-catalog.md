# 옴니노드 시스템 기본 템플릿 카탈로그

> 분류: 프로젝트 설계
>
> 근거: 확정 1차 기획, 데이터 스키마, 마스터의 2026-09-10 정정, 프로젝트 위그드라실 공통 템플릿 정본
>
> 범위: 시스템 기본 템플릿의 공통 정본과 11개 메인 카테고리 기본 연결을 정의한다. 프로젝트 사용자 정의 템플릿, 세계관별 이관 템플릿, ORM, 시드 코드와 마이그레이션은 포함하지 않는다.

## 공통 원칙

1. 시스템 기본 템플릿은 이미 확정된 공통 정본이다. 룩스테라·엘드로스의 개별 템플릿 파일은 이 정본을 대체하지 않으며, 해당 세계관의 프로젝트 사용자 정의 또는 이관 템플릿으로 취급한다.
2. 시스템 기본 템플릿은 공통 11개 메인 카테고리에 하나씩 대응한다. 새 프로젝트는 11개 시스템 기본 템플릿을 모두 참조 상태로 만들고, 각 메인 카테고리에 대응 템플릿을 기본 연결한다.
3. 모든 기본 템플릿의 첫 필수 섹션은 `개요`, 마지막 고정 섹션은 `요약`이다. 중간 필수 섹션은 아래 카탈로그의 순서를 따른다.
4. 템플릿의 필수 `##` 섹션은 삭제하거나 숨기지 않는다. 프로젝트별 다른 구조가 필요하면 시스템 템플릿을 바꾸지 않고 프로젝트 사용자 정의 템플릿을 만든다.
5. 공통 카테고리의 하위 분류는 메인 카테고리의 기본 템플릿을 사용한다. 하위 분류 전용 양식이 필요하면 해당 프로젝트에서 사용자 정의 템플릿을 만들고 메인 카테고리 연결을 바꾼다.

`설정_대륙 템플릿`은 공통 정본에 있는 지형 하위 유형용 전문 양식이지만, 현재 제품은 대분류에만 기본 템플릿을 연결한다. 따라서 시스템 기본 11종의 자동 연결에는 넣지 않는다. 대륙 전용 구조가 필요한 프로젝트는 이 공통 구조를 근거로 프로젝트 사용자 정의 템플릿을 만들어 지형 메인 카테고리에 연결한다.

## 정본 이력과 반입 규칙

공통 11종의 원문 구조는 프로젝트 위그드라실 Git 이력 `9e40649`의 `프로젝트 위그드라실/md/프로젝트 위그드라실 템플릿 체계 및 Sanity 이관 명세.md`에 보존되어 있다. 해당 문서가 기록한 공통 템플릿 정본을 마스터가 현재 시스템 기본 기준으로 확인했다.

M02 구현 전에 이 카탈로그의 11종과 섹션 순서를 Omninode 저장소의 버전 관리 JSON 스냅샷으로 반입한다. 시드에는 이 카탈로그의 템플릿 이름·섹션 순서만 사용하며, 룩스테라·엘드로스의 개별 템플릿 문장·중복 헤딩·세계관 고유 섹션을 자동 병합하지 않는다.
