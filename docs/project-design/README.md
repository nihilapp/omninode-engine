# 프로젝트 설계

옴니노드 서비스 전체에 지속적으로 적용되는 제품 원칙과 구조를 기록한다.

여기에는 서비스 목적, 사용자 역할과 권한, 월드·프로젝트·문서 같은 도메인 구조, 데이터 보존 원칙, 공통 화면 정책, 확정된 요구사항 결정을 둔다.

서비스 전체가 지속적으로 따라야 하는 공개 라우트와 API 계약은 제품 경계로서 이 폴더에 기록한다. 특정 구현 작업의 순서, 파일 변경 목록과 테스트 계획은 `docs/work-design/`에 기록한다.
