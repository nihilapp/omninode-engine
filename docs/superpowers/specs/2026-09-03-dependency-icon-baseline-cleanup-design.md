# 의존성·아이콘 기준선 후속 정리 설계

> 작성일: 2026-09-03

> 상태: 마스터 승인

> 선행 설계: `docs/superpowers/specs/2026-09-03-quality-baseline-recovery-design.md`

## 목적

품질 기준선 복구 뒤 남은 보안 권고와 클라이언트 대형 청크를 현재 프로젝트가 직접 해결할 수 있는 범위에서 정리한다. 호환 가능한 패치는 적용하되, 사용하지 않는 선택 의존성이나 상위 도구가 고정한 비호환 의존성은 원인을 기록하고 후속 구현을 막지 않는다.

## 현재 상태

- `fast-uri@3.1.5`는 현재 의존 범위 안에서 `3.1.6`으로 패치할 수 있다.
- `mysql2@3.15.3`은 Prisma가 고정한 선택 의존성이며, 이 프로젝트의 실제 데이터베이스 연결은 PostgreSQL 어댑터를 사용한다.
- `deepmerge-ts@7.1.5`는 Prisma 설정 도구가 고정한 의존성이며, 수정판은 호환되지 않는 주 버전 `8`이다.
- 프로덕션 서버 산출물에는 `fast-uri`, `mysql2`, `deepmerge-ts`가 포함되지 않는다.
- 클라이언트의 약 14.9 MB 청크는 네 아이콘 컬렉션 전체를 런타임 데이터로 가져오는 구조에서 발생한다.
- 앱이 현재 직접 참조하는 아이콘은 `lucide:copyright`, `lucide:home`, `lucide:menu`, `mdi:github` 네 개다.

## 범위

### 포함

- pnpm override를 통한 `fast-uri@3.1.6` 적용
- 앱 소스에서 정적 아이콘 이름을 수집하는 생성기
- 참조 아이콘과 필요한 별칭 부모만 포함하는 최소 아이콘 데이터 생성
- 실제 참조 아이콘만 허용하는 `UiIconName` 타입 생성
- 생성 로직의 단위 테스트와 전체 품질 검증
- 남은 상위 의존성 권고의 분리 기록

### 제외

- Prisma 내부의 `mysql2` 버전을 강제로 교체하는 override
- `deepmerge-ts`를 호환되지 않는 주 버전으로 강제 교체하는 override
- Prisma 포크, 패치 패키지 또는 상위 패키지 직접 수정
- 제품 페이지·API·데이터베이스 기능 변경
- 동적 아이콘 로더나 네트워크 아이콘 조회 추가

## 설계

### 의존성 패치

루트 `pnpm-workspace.yaml`의 override는 `fast-uri@3.1.5`만 `3.1.6`으로 치환한다. 설치 뒤 잠금 파일과 `pnpm audit`를 확인한다. `mysql2`와 `deepmerge-ts`는 실제 프로덕션 산출물에 포함되지 않고 현재 상위 의존성의 호환 가능한 수정 경로가 없으므로 이번 범위에서 종료한다.

### 아이콘 참조 수집

생성기는 `app/` 아래의 `.ts`, `.vue` 파일에서 지원 접두사와 정적 이름으로 이루어진 아이콘 문자열을 찾는다. 다음 파일과 경로는 생성 입력에서 제외한다.

- `app/scripts/`
- `app/data/icons.data.ts`
- `app/types/icon.generated.ts`

지원 접두사는 `game-icons`, `lucide`, `mdi`, `simple-icons`다. 결과는 중복을 제거하고 사전순으로 정렬한다. 동적으로 조립한 이름은 자동 발견 대상으로 보지 않으며, 동적 이름이 실제로 필요해질 때에는 생성기의 명시적 포함 목록에 등록한다.

### 최소 아이콘 데이터

수집한 각 이름이 원본 컬렉션의 아이콘 또는 별칭인지 검사한다. 존재하지 않으면 생성 작업을 실패시켜 잘못된 이름이 런타임까지 넘어가지 않게 한다.

직접 아이콘은 해당 데이터만 포함한다. 별칭은 별칭 데이터와 최종 원본 아이콘에 도달하는 부모 사슬을 함께 포함한다. 컬렉션의 기본 너비와 높이는 보존한다. 생성된 `app/data/icons.data.ts`는 원본 아이콘 패키지를 import하지 않고 최소 JSON 데이터만 export한다.

### 생성 타입

`app/types/icon.generated.ts`는 수집한 이름만 접두사별 union으로 생성한다. 참조가 없는 접두사 타입은 `never`로 생성하고, 지원 접두사의 `IconPrefix`와 네 접두사 타입을 합친 `UiIconName`을 함께 제공한다. 기존 `UiIcon`의 prop과 렌더링 API는 바꾸지 않는다.

## 검증 기준

- 생성 로직 테스트가 정적 이름 추출, 중복 제거, 정렬, 미존재 아이콘 거부, 별칭 부모 보존을 검증한다.
- `pnpm icon:gen`을 연속 두 번 실행해 생성 결과가 바뀌지 않는다.
- 생성 데이터에 아이콘 패키지의 런타임 import가 남지 않는다.
- `pnpm audit`에서 `fast-uri` 권고가 사라진다.
- 남는 권고는 `mysql2`와 `deepmerge-ts`의 상위 의존성 경로로만 한정된다.
- 테스트, 린트, 타입 검사, Nuxt 준비, 빌드와 `git diff --check`가 통과한다.
- 빌드에서 기존 약 14.9 MB 클라이언트 청크와 500 kB 초과 경고가 사라진다.

## 후속 판단

Prisma가 호환 가능한 `mysql2`와 `deepmerge-ts` 버전을 채택하면 일반 의존성 갱신 과정에서 다시 감사한다. 그전까지 두 권고는 제품 기능 구현의 선행 장애로 취급하지 않는다.
