# 작업 설계

특정 기능이나 변경 작업을 실제로 구현하기 위한 설계를 기록한다.

여기에는 작업 목적과 범위, 영향을 받는 화면·데이터·API, 구현 순서, 검증 방법, 완료 기준을 둔다.

서비스 전체에 계속 적용되는 제품 원칙이나 확정 요구사항은 이 폴더에 기록하지 않는다. 그런 내용은 `docs/project-design/`에 기록한다.
